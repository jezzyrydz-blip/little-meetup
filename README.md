# Little Meetup

A tiny town where little avatars hang out on plots **you** create, then start groups around what they like.

## What you can do

- Make a cute avatar (color, face, hat, name)
- Create a plot for what you like (name, vibe, emoji, color, category)
- Visit that plot, walk around, and wave
- Create or join groups tied to a plot

Everything saves in your browser. There are no starter plots — the map starts empty until you plant one.

## Create a plot

1. Enter town with your avatar
2. Click **Create a plot**
3. Name it, say what people like there, pick a category, emoji, and color
4. Click **Plant this plot** — you land in the hangout park

## Run it

Open `index.html` in a browser, or visit `http://localhost:5173` if a local server is running.
